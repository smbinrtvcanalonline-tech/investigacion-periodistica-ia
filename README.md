# Investigación Periodística IA

## Plataforma de Inteligencia Artificial para Periodismo de Investigación y Transparencia Pública

**Investigación Periodística IA** es un proyecto de código abierto desarrollado para apoyar a periodistas, investigadores y ciudadanos en el análisis de información pública mediante inteligencia artificial.

## Objetivo

Crear una plataforma tecnológica capaz de analizar documentos, expedientes, presupuestos públicos, informes de auditoría y contrataciones del Estado, fortaleciendo la transparencia y el acceso a información de interés ciudadano.

## Capacidades del sistema

- Análisis inteligente de documentos PDF.
- Extracción y organización de información.
- Generación de resúmenes ejecutivos.
- Detección de posibles riesgos e inconsistencias.
- Evaluación de evidencia documental.
- Análisis presupuestal y económico.
- Verificación de referencias normativas.
- Generación de informes periodísticos.
- Automatización mediante n8n.
- Integración con modelos de inteligencia artificial locales.
